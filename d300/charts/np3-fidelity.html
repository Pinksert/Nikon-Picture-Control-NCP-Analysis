一、先说一个和直觉相反的事实

把 26 个原始 NP3 的参数卡全部导出来之后，结果是这样的：

卡名字26 支里的情况
8对比度全部 = 0
9亮度20 支「不适用」+ 6 支 0
10饱和度20 支「不适用」+ 6 支 0
11色相20 支「不适用」+ 6 支 0

真正带数值的只有五项：锐化、清晰度、调色强度、效果级别、快速锐化。

也就是说：每支滤镜的影调与色彩个性，既不在参数里，也不在 NP3 文件里， 而是编在底子码指向的内置曲线里（0801–0814 二十个创意底子， 加上 0001 / 03C2 / 00C3 / 0486 / 04C7 / 064D / 028E）。

这解释了一件事：NCP 里那些「饱和度 −3」「色相 +3」，在原版 NP3 里没有任何对应参数。 它们不是照抄，是为了逼近「底子曲线自带的色彩效果」而加的补偿量。

除了最暗那一档（量化噪声），各档倍率基本恒定 —— 一个倍率作用在全画面。

D300 能做的只有「整体乘一个系数」；原版做的是「低彩度压到接近零、高彩度基本保留」， 那是一根作用在 彩度轴 上的 S 曲线。
一条作用在 亮度轴 上的自定义曲线，改不了彩度轴上的形状。

五、结论

层能否完全模拟现状
参数（锐化、调色类型、强度）基本能 25 / 26 一致；DREAM 锐化钳位是唯一硬损失
影调（亮度响应）能，且已做到 真机中间调 1.7–3.7 级；场景内 30 对平均 6.17 级
颜色（彩度响应形状 + 分色相矩阵）不能 只有「一条亮度 LUT + 一个线性倍率 + 一个全局色相角」

影调可以做到「看不出来」，颜色只能做到「同一个风格」。
说「完全模拟」不成立 —— 不是没调好，是 D300 的引擎里没有那两个旋钮。

还剩一个没试过的自由度

已用掉：标准底子 + 自定义曲线 + 锐化/饱和/色相/调色四个滑块。
没用过：D300 另外四个原生底子（中性 03C2、鲜艳 00C3、人像 0486、风景 04C7）。

现在是一律「标准底子 + 负饱和压下去」。而负饱和是线性乘法，不同底子自带的彩度起点本来就不同：

  • 需要「大幅压彩度」的七支（DRAMA / SILENCE / BLEACH / MELANCHOLIC / PURE / FLAT / FLEXIBLE_COLOR） 已压到 −3 档（硬件下限）仍不够 → 换中性底子做载体，起点就低；
  • POP / VIVID / TOY 需要更高彩度 → 换鲜艳底子，不必把滑块顶到 +3。

这条路不需要任何新滑块，只需换底子码 + 重拟合曲线，文件结构完全合法。 但换底子会同时改变影调（曲线能吸收）和色彩处理（曲线吸收不了），两者各占多少，只能靠一次渲染实测。

⚠️ 早期记录里「03C2 等 D300 不认」的结论，来自滑块还写 80 80 的轮次 —— 那种情况下单色文件本身会因「底子与滑块类型矛盾」被跳过，归因不干净。目前只能说「没有干净的单变量复测」， 不能断言不认。
