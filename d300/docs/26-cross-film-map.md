# 26 · 跨底片映射：能不能把 4484 那张表搬到别的图上用

> 状态（2026-11-02 22:40）：做完了。结论是**不能白拿**，但有一块能白拿。
>
> - **换输入域没用**。把 LUT 的输入从「我们的成片」换成「不经过 Picture Control 的中性锚点」，
>   跨底片不确定性从 **6.3 倍升到 4.8 倍**（绝对值 4.07 → 4.80）。这条路走不通。
> - **空格子是真的一块，而且能免费修**。表是在一张图上拟合的，标定图没采到的格子保持恒等，
>   新图落进去等于没查表。把这些格子按邻居扩散补上：26 支 × 2 方向 **3.71 → 3.42**，
>   20 支变好，未覆盖比例与收益的相关系数 **r = 0.76**。
> - **整图级补偿（一支参考滤镜现场解 12 个参数）不成立**。逐支解有用（3.42 → 2.84，26/26 变好），
>   但一支参考滤镜解出的 `g` 套到别的支上是 **12 支变好、14 支变坏**，净收益只有 0.03。
> - 所以「跨底片映射」的正确形态不是一张通用表，而是**把按图标定的成本压到一条命令**：
>   `lut_fit.py --fill-gaps`（免费那块已经在里面了）+ 新底片全部走一遍（留出 **2.16**）。

## 一、问题与判据

`docs/25` 留下了这个数：

| | ΔE00 |
|---|---|
| 在 4484 上标定（同图 2×2 留出） | 2.13 |
| 把 4484 的 `.cube` 直接套到 8981 | 3.33 |
| 在 8981 上重新标定（留出） | 2.19 |

差的那 1.2 分，能不能补掉、怎么补，就是本文要回答的。判据只有一条：
**留一底片（LOFO）**——在一张图上标定，整套拿到另一张上打分，再反过来。
同图 2×2 留出只能测「没见过的像素」，测不出「换了一张图」，那是两回事。

## 二、假设一：换输入域（否掉）

**想法**：`docs/25` 发现「同一个我们的 RGB，官方在两张底片上给出差 4.07 级的输出」。
如果原因是「我们的成片是 raw → 我们的 NCP → 成片，NCP 把彩度塌缩、把彩色压成黑白，
信息在那一步丢了」，那么换一个不经过 NCP 的输入域就能救。

**做法**：`tools/anchor_render.py` 造中性锚点——rawpy 关掉一切逐图自适应
（`no_auto_scale`、`no_auto_bright` 全关，白电平用相机常数 4095，as-shot 白平衡），
线性归一后过 sRGB 编码。它几乎是 raw 的双射，只丢掉高光溢出那一点（4484 是 1.6%）。
然后用 `tools/crossfilm_domain.py` 在**同一套像素掩膜**下量两个域：

| 输入域 | 跨底片 | 同图内 | 倍数 |
|---|---|---|---|
| O：我们的成片 | 4.07 | 0.65 | 6.3x |
| A：中性锚点 | **4.80** | 1.00 | **4.8x** |

**换域没降，绝对值反而升了。** 说明这 4 级不确定性不是「我们的成片丢了信息」造成的，
是官方渲染本身在吃「这张图」。锚点这个工具本身有用（它是一张不依赖 NX Studio 的中性渲染），
但拿它当 LUT 的输入域救不了跨底片。

顺带把「是不是邻域/锐化这类空间效应」也排了一下——同一套量法，只改采样尺寸：

| 长边 | 跨底片 | 同图内 | 倍数 |
|---|---|---|---|
| 420px | 4.07 | 0.65 | 6.3x |
| 210px | 3.69 | 0.79 | 4.6x |
| 105px | 3.37 | 1.00 | 3.4x |

降到 105px（几乎全是低频）还有 3.4 倍，所以**既有空间成分，也有补不掉的全局成分**。
这也预告了后面两节的结果：全局那块靠整图变换去补，空间那块谁也补不了。

## 三、假设二：空格子（确认，可免费修）

**想法**：3D LUT 是在一张图上拟合的，网格里只有**被那张图采到过的格子**才有值。
`lut_fit.splat_avg()` 的规则是「该格附近样本少于 0.02 就当 0 残差」——也就是**保持恒等**。
在那张标定图上永远走不到这些格子，所以看不出来；换一张图，只要它的颜色落进来，
查表就等于什么都没做。这不是「映射不确定」，是**覆盖不足**，能修。

**做法**：`tools/crossfilm_coverage.py`。把「源底片样本 < 3」的格子标为空，
用 Jacobi 迭代把残差从有值的格子往空格子里扩散（有值处当边界条件，60 轮），
得到一张在整个色域里处处有定义的表。实现已经并进 `lut_fit.fill_grid_gaps()`。

| | ΔE00 |
|---|---|
| 直接套 | 3.71 |
| 补空洞 | **3.42** |

20/26 支变好，未覆盖率均值 5.2%、最大 18.1%，**与收益的相关系数 r = 0.76**。
收益最大的是 NEUTRAL（−0.95）、STANDARD（−0.58）、DENIM（−0.44）、TOY（−0.41），
正好也是未覆盖率最高的那几支（9–12%）。对应关系是干净的。

**这一块不需要任何额外导出，是纯收益。** 它现在已经是标定流程的一部分：
`lut_fit.py --fill-gaps`。

## 四、假设三：整图级补偿（逐支有效，共用无效）

**想法**：既然第二节证明「官方吃整图」，那就把这一维显式建模成一个**整图共用的 3×4 颜色仿射**，
放在 LUT 前面（预补偿）或后面（后补偿）：

```
预补偿：T ≈ LUT(g(O))        g(x) = M x + b，12 个参数，整图共用
后补偿：T ≈ g(LUT(O))
```

预补偿的 `g` 用高斯-牛顿解（LUT 的局部雅可比是解析的），初值取恒等，2–3 轮收敛。
`tools/crossfilm_calib.py` 是这一节的实验台。

| 方案 | 参考滤镜 | ΔE00 | vs 直接套 | 改善支数 |
|---|---|---|---|---|
| 直接套 | — | 3.71 | — | — |
| 补空洞 | — | 3.42 | −0.29 | 20/26 |
| 补 + 逐支后仿射 | 每支各自解 | **2.84** | −0.88 | **26/26** |
| 补 + 逐支预仿射 | 每支各自解 | 4.54 | +0.83 | 19/26 |
| 补 + 共用后仿射 | STANDARD | 3.98 | +0.27 | 7/26 |
| 补 + 共用预仿射 | STANDARD | 3.56 | −0.15 | 13/26 |
| 补 + 共用后仿射 | NEUTRAL | 3.48 | −0.23 | 17/26 |
| 补 + 共用预仿射 | NEUTRAL | **3.39** | −0.32 | 16/26 |

三件事同时成立，而且互相印证：

1. **整图这一维确实存在**：逐支解出来的仿射把 3.42 推到 2.84，26 支全部变好。
2. **但它不是「所有支共用一个」**：一支参考滤镜解出的 `g` 套到其余 25 支上，
   净收益只有 0.03（3.42 → 3.39），而且是 **12 支变好、14 支变坏**。
   最典型的是 DREAM：机内 6.66，直接套 cube 是 1.33，再叠上 STANDARD 解出的 `g` 变成 2.89。

   这一条不是调参问题，是可以推出来的。整图补偿要生效，必须作用在 **u 域**
   —— 也就是"套滤镜之前的那张图"。我们手里只有 `O = Ψ_k(u)`，而 `Ψ_k` 逐支不同、且**不可逆**
   （`docs/25` 第五节量出的「跨底片 4.07 / 同图内 0.65」就是它不可逆的证据：
   同一个 O 对应许多个 u）。于是在 O 域上解出的 `g`，只对解它的那一支 k 近似等于"u 域补偿"；
   换一支，`g` 落到的是一个完全不同的曲面上，就不再是补偿而是干扰了。
   逐支解能到 2.84、共用只有 3.39，差的就是这一层。
3. **预补偿对单色支会发散**：逐支预补偿 4.54，比不补还差。原因是单色 LUT 把整个色域映射到
   一条灰线上，雅可比在彩度方向奇异，高斯-牛顿一解就飞（BINARY 48.6、CHARCOAL 33.7）。
   这不是调参问题，是这类表本来就没有可逆的输入方向。

第 3 条也解释了 `docs/25` 第六节那个「逐通道分位数配准」为什么失败：
思路是同一个（把这张图摆回标定图的位置），但那时用的是 3×256 个自由度的单调曲线
去匹配边缘分布，目标函数错了、自由度又太多，BINARY 直接爆到 24.82。
现在的版本是 12 个自由度、目标函数是真值，不炸了——**但也只对解它的那一支有效**。

## 五、结论：什么能跨，什么不能

| 能拿到的东西 | 代价 | ΔE00 |
|---|---|---|
| 补空洞（表在色域里处处有定义） | **0** | 3.71 → 3.42 |
| 一支参考滤镜的整图补偿 | 1 支配额 | 3.42 → 3.39（且有 14 支变坏） |
| 每支各自解整图补偿 | 26 支配额 | 3.42 → 2.84 |
| 按图重标定（26 支全导一遍） | 26 支配额 | **2.16**（留出，中位 1.61） |

看最后两行：**「每支各自解 g」和「按图重标定」要付一样的导出成本，但重标定更好**
（2.84 vs 2.16）。那整图补偿这一族就没有存在意义了——它唯一的价值是"导出便宜"，
而它的共用版本便宜却几乎没用。

所以准确的结论是：

> **跨底片的差距不是「一张表没调好」，而是「这张表只在这张图上被定义过」。**
> 能免费补的只有覆盖不足那 0.29；剩下的 1.2 分必须用新底片自己的真值，
> 而一旦有了真值，直接重标定比"迁移+补偿"更省事也更好。

这也把 `docs/25` 那句话收紧了：不是「LUT 必须按底片标定」，而是
**「LUT 捕捉的是这一张图的映射，换图就该重标，重标只要一条命令」**。

## 六、所以怎么用

**给新底片做一套表**（推荐，唯一正确的用法）：

```bash
# 在 NX Studio 里，用同一张 NEF，把 26 支各导两遍（我们的 NCP / 官方 NP3），
# 文件名保持 NN_名字__O.* 和 NN_名字__T.*，放进同一个目录，然后：
python tools/lut_fit.py --v3 in/ --target in/ \
    --suffix-o __O --suffix-t __T \
    --fill-gaps --lut-dir lut_8981 --out lut_8981/metrics.csv
```

`--fill-gaps` 一定要加：它让表在色域里处处有定义，别的图套上去不会掉回原样（−0.29）。
`--lut-dir` 一定要指到新目录，否则会覆盖掉 4484 那套。

**只是想粗用 4484 那套表**：别直接套。`docs/25` 第七节的门槛仍然成立——
机内 ΔE00 过 3 才值得套，没过 3 直接机内更好。

**手里只有一支滤镜的真值**（比如只导了 STANDARD）：`tools/lut_transfer.py` 可以解一个
整图 `g` 再套其余 25 支，但**先看第四节**：它会让 14 支变坏。不建议默认打开。

```bash
# 解 g
python tools/lut_transfer.py --ref-cube lut/29_STANDARD.cube \
    --ref-ours ref/29_STANDARD__O.jpg --ref-official ref/29_STANDARD__T.jpg \
    --save g.json
# 套用（谨慎）
python tools/lut_transfer.py --affine g.json --cubes lut \
    --in-dir ours/ --out-dir out/ --strip __O
```

## 七、还没解开的

- **官方到底在吃什么**：420px→105px 降采样后仍有 3.4 倍，说明有一个全局成分；
  这个成分是什么（直方图锚定的色调曲线？高光恢复？默认降噪？）还没定位。
  定位它才有机会把整图补偿做成"不需要真值、从图像统计直接算"的版本。
- **只有两张底片**：12 个参数的 `g` 靠两支标定，不够做「用图像统计预测 g」的回归。
  要 8–10 张不同影调/题材的底片才谈得上。
- **机身直出 vs NX Studio**（`docs/24`/`docs/25` 的遗留问题）：这套 LUT 全是在 NX 导出的 JPG 上标的，
  机身直出的 JPG 是不是同一条渲染路径还没验。如果是两条路，跨底片的问题在机身上会另有一套。
