# 尼康工坊（NX Studio）测试指南

本机已装 **NX Studio 1.10.0**（`C:\Program Files\Nikon\NXStudio`），可以直接测，不用插卡。

---

## 一、这轮到底在测什么

工坊能替我们回答四个问题，这四个问题插卡测不出来（插卡只能看到"载入成功/失败"）：

| 编号 | 要验证的事 | 失败意味着 |
|---|---|---|
| **A** | 尼康的解析器认不认这批 638 字节的 NCP | 文件结构有问题，插卡也白搭 |
| **B** | 名字、底子、滑块有没有被正确读出来 | 名称字段或底子编号写错了 |
| **C** | 那条自定义曲线有没有**真的生效** | 曲线被忽略 → 效果等于"只有滑块"，白做 |
| **D** | 单色「调色」枚举猜得对不对（棕褐/粉色） | 这是源文件里查不到信息、只能靠枚举顺序推的两项 |

**工坊测不了的**：机身固件是否接受（工坊解析比机身宽松）、以及机身色彩引擎与电脑端的细微差异。所以工坊通过 ≠ 一定能装机，但工坊不通过就一定装不上。

## 二、准备

1. 从卡上拷 **2 张 D300 的 NEF** 到电脑任意文件夹（例如 `D:\NCP测试\`）：
   - 一张**正常曝光的风景或人像**（能看整体影调）；
   - 一张**暗部有细节 + 高光不过曝**的（能看出抬黑/压白这类变化）。
   - 没有 NEF 的话，先拿一张 JPG 试，但「优化校准」面板对 JPG 可能是灰的，那就必须用 NEF。

2. 测试包在 `D300_NCP\测试包\`，8 个文件，覆盖了要验的全部情况（见第四节）。

## 三、导入（中文界面实际文字已核对）

**方式一（推荐，从文件导入）**

1. `文件` 菜单 → **`导入自定义优化校准(&I)…`**
   （或点工具栏的 **`自定义优化校准`** 按钮，提示语是"导入或导出自定义优化校准"）
2. 在「导入自定义优化校准」对话框里选 **`从文件导入`** → 确定
3. 源目录填 `D:\Documents\Workbuddy\D300\D300_NCP\测试包`，**可一次多选 8 个** → 确定
4. 正常会弹出导入结果，列表里出现 8 个名字并标出底子

**方式二（从存储卡，只有装相机时才用）**
卡必须是相机格式化过的（根目录要有 `DCIM` 和 `NIKON001.DSC`），否则工坊扫不到。

> 容量限制：工坊内最多存 150 个自定义优化校准，卡上每种类型（NCP/NP2/NP3）最多 99 个。我们 30 个，远没到限。

**导入后要记下两件事**：①有没有报错、报错列了哪几个文件；②列表里显示的名字是不是 `DREAM / CHARCOAL / BINARY …` 这种（如果显示成 `????` 或乱码，说明名称字段写法不对）。

## 四、逐个套用并核对（按这个顺序）

打开 NEF → 右侧 **`调整`** 板块 → **`优化校准`** 下拉 → 在 **`保存的自定义优化校准`** 分组里选。

| 顺序 | 文件 | 中文名 | 底子 | 该看什么 |
|---|---|---|---|---|
| 1 | PICCON29 | 标准（新系统版） | 标准 | **对照组**。应接近机身「标准」，但高光略提亮（+13~15/255）。若出来是灰蒙蒙或反相，说明底子/曲线全错了 |
| 2 | PICCON21 | 平面 | 标准 | 暗部抬到 14/255 左右、整体低反差。曲线是否生效看这个最直观 |
| 3 | PICCON01 | 梦幻 | 标准 | **暗部抬得很厉害（黑场到 47/255 ≈ 18% 灰）**。这是实测曲线本身如此，不是 bug。若一点都没抬，就是曲线没生效 |
| 4 | PICCON17 | 木炭 | 单色 | 应先变黑白，再抬黑压白（黑 23、白只到 242）。**先黑白后影调**，两步都要有 |
| 5 | PICCON19 | 双色 | 单色 | 极硬调：输入约 140 以下全黑、以上全白，中间几乎无过渡。**这是控制点上限的压力测试**（我用了满 20 点，尼康原厂样本只用 3~4 点） |
| 6 | PICCON13 | 棕褐色 | 单色 | 应显示为黑白＋**棕褐调色**。看 `调色` 项显示的是不是「棕褐」——这是枚举验证点 ① |
| 7 | PICCON16 | 粉色 | 单色 | 应显示为黑白＋**红紫（偏粉）**调色。看 `调色` 项显示什么——枚举验证点 ② |
| 8 | PICCON03 | 流行 | 标准 | 高饱和、高光提亮 +22~24。检验颜色天花板（这项天生做不到位，只看方向对不对） |

## 五、客观验证：导出回来做字节比对（关键一步，30 秒）

肉眼看"像不像"会有主观误差，但曲线有没有被保留是**可以量化判定**的：

1. 工坊里 `文件` 菜单 → **`导出自定义优化校准(&E)…`**
2. 选刚导入的其中一个（建议拿 **PICCON01 梦幻**，它的曲线偏移最大，最容易看出被改），导出到一个空文件夹，例如 `D:\NCP测试\导出\`

## 六、失败现象对照

| 现象 | 大概率原因 | 处理 |
|---|---|---|
| 导入直接报错、文件被列进失败清单 | 结构或底子编号不被接受 | 把报错原文发我 |
| 名字显示乱码 / 空白 | 名称字段编码不对 | 我改 ASCII 填充方式 |
| 面板里曲线是直线（无偏移） | 曲线块被忽略 | 说明 20 个控制点不被接受，我改成 3~4 点 |
| 套用后变成全黑或全白 | 曲线方向反了（LUT 端点理解错） | 我翻转 LUT 重出 |
| 棕褐 / 粉色显示出别的颜色名 | 调色枚举猜错 | 按工坊显示的真实名字反推，一次改对 |
| 变形/色块 | 曲线非单调，机身引擎不接受 | 我强制单调重出 |
| 优化校准面板整块灰显 | 当前是 JPG，工具只对 RAW 开放 | 换 NEF |

## 七、测完请告诉我这四件事

1. 导入有没有报错，报错原文是什么；
2. 列表里的名字对不对（尤其有没有乱码）；
3. 上面 8 个里，哪几个"影调方向明显不对"（不用评价好不好看，只说方向和预期表符不符）；
4. 棕褐、粉色这两个的 `调色` 项在工坊里显示成什么名字。

有这四条，我就能判断是结构问题、曲线问题还是枚举问题，改一次到位，不用反复试。
