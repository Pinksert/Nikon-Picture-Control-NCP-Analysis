# 第三轮测试：插卡到 D300 实拍

---

## 零、这一版修了什么（上一版只显示 4 个的原因）

上一版 11 个文件，机身「载入」列表里只有 `T06 STEP`、`T04 COMP`、`T03 BASE`、`FLAT` 四个。
分界线非常整齐：**能显示的底子码都是 `0x0001`，不能显示的都是 `0x064D`**。

查 D300 SDK §6.4.1 定案了：

> PicCtrlItem: **1: Standard, 2: Neutral, 3: Vivid, 4: Monochrome**，
> 101–199: Option（自定义位填「所依据的底子」）

D300 自己的优化校准编号就是 **1/2/3/4**。`0x064D` 是**新系统**（NP2/NP3 那一代）的单色码，
`0x03C2` 中性 / `0x00C3` 鲜艳 / `0x0486` 人像 / `0x04C7` 风景 也一样 —— D300 一个都不认。

顺带查出第二个错：原厂单色文件的八滑块是

```
83 80 80 FF FF 80 80 FF      ← MONOCHROME.NCP
         ↑  ↑  饱和度 / 色相 = 不适用
```

而我上一版写成了 `83 01 01 80 80 80 81 84` —— 单色底子上根本没有「饱和度 / 色相」这两档，
给了值就与底子矛盾。底子码和滑块两处都已改正，另外体检里加了这条一致性检查，以后不会再漏。

## 一、装卡

1. 卡插读卡器；
2. 把 `卡片包\NIKON` 整个文件夹拷到卡根目录（结果是 `卡:\NIKON\CUSTOMPC\PICCON01.NCP` … `PICCON12.NCP`）；
3. 覆盖掉上一版的同名文件，安全弹出。

> 路径必须是 `NIKON\CUSTOMPC\`。这条来自固件字符串 `A:\NIKON\CUSTOMPC\PICCON%02d.NCP`，不是猜的。

| 卡上文件 | 机内显示名 | 底子 | 字节 | 作用 |
|---|---|---|---|---|
| PICCON01 | `T06 STEP` | 标准 | 638 | 主探针：v=128 硬阶跃 |
| PICCON02 | `T04 COMP` | 标准 | 638 | 补偿后的恒等曲线 |
| PICCON03 | `T03 BASE` | 标准 | 52 | 基准：无曲线 |
| PICCON04 | `FLAT` | 标准 | 638 | 平面：20 点连续曲线 |
| PICCON05 | `BINARY` | 单色 | 638 | 双色：阶跃，H 的独立交叉验证 |
| PICCON06–11 | `SEPIA T0…T4` / `TNA` | 单色 | 638 | 棕褐浓度阶梯 0x80…0x84 / 0xFF |
| PICCON12 | `MONO 52` | 单色 | 52 | **二分探针**：原厂单色只改底子码 |

## 二、先只做一件事：看列表

卡插回机身 → **拍摄菜单 → 管理优化校准 → 载入/保存 → 复制到相机**

**先不装，只数一下列表里有几个名字，告我一声。**

判读很快：

| 列表里出现的 | 说明 | 下一步 |
|---|---|---|
| **12 个全出现** | 底子码修对了，单色这条路通了 | 进第三步，注册 + 拍摄 |
| 标准底子的 4 个 + `MONO 52`，但 638 字节的单色不出现 | 底子 `4` 对，问题在「单色 + 曲线」这个组合 | 别拍，我先单独查这一条 |
| 还是只有那 4 个，`MONO 52` 也没有 | 底子 `4` 也不对，或单色还有别的必填项 | 别拍，我改探针再来一次 |

`MONO 52` 这个文件就是为区分后两种情况专门加的：它是**尼康原厂 `MONOCHROME.NCP` 原样**，
只把底子码从 `0x064D` 改成 `0x0004`，其他一个字节没动。

## 四、拍摄设置（会叠加在优化校准之上，别漏）

| 项目 | 设为 | 原因 |
|---|---|---|
| 曝光模式 | **M** | 十张完全同曝光 |
| ISO / 光圈 / 快门 | 固定，拍完不许改 | 同上 |
| 白平衡 | **手动预设或固定 K 值**，不要自动 | 自动白平衡会逐张漂 |
| 动态 D-Lighting | **关闭** | 它自己就改曲线 |
| 高 ISO 降噪 / 长时间曝光降噪 | 关闭 | |
| 自动失真控制 | 关闭 | |
| 图像品质 | **JPEG Fine / L** | 我要读相机自己渲染的结果 |

**取景**：亮度连续的画面，有暗部、有中间调、高光不溢出。取景固定后整组别动、别变焦、别改光。
**先拍一张试的**，机背直方图确认左边不贴死、右边不爆掉。
