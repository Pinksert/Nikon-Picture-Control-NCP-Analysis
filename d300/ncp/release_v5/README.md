# release_v5 —— 单色 5 支（v4 + BINARY 换绿滤镜）

与 `release_v4` 的差别只有**一个字节**：

| 文件 | 槽 | 改动 |
|---|---|---|
| `PICCON19.NCP` | 19 BINARY | 第 45 字节 `0x80`（滤镜关闭）→ `0x84`（绿滤镜） |
| 其余 4 支 | 17 / 18 / 20 / 27 | 与 v4 逐字节相同，未重写 |

曲线一处未动。BINARY 的曲线修不动（重拟合留出更差，见 `docs/24` 第四、五节），
能动的只有黑白混色权重这一格。

## 为什么要换成绿

D300 说明书 p151 的滤镜枚举是 `关闭 / 黄 / 橙 / 红 / 绿 = 0..4`，
而 `docs/24` 第六节实测出黄/橙/红**方向全反**（越走越远，6.98 → 17.86）：

| 档 | 关闭 `0x80` | 黄 `0x81` | 橙 `0x82` | 红 `0x83` | 绿 `0x84` |
|---|---|---|---|---|---|
| BINARY ΔE00 | 6.983 | 8.733 | 14.671 | 17.856 | **6.239** |
| MONOCHROME ΔE00 | **1.183** | 1.492 | 2.576 | 3.984 | 1.309 |

绿是唯一反向的一档（压红、提绿），也是 BINARY 唯一一次真的下降：
6.983 → 6.239（−0.74，−10.6%）。分歧像素总数几乎没变（2214 → 2391），
但「我们白/官方黑」里的红主导从 73% 掉到 44% —— 色偏被抹平，净值仍为正。

**MONOCHROME 不要跟着改**：它在 `0x80` 就有 1.18（分歧只有 300 像素），加绿反升到 1.31。

5 支单色均值：2.36 → **2.12**。

## 怎么用

整目录替换卡上的 `NIKON/CUSTOMPC/`，或在 NX Studio 里逐个导入。
判读要用相机：同一张 NEF，用新包与 `release_v4` 各导一张，再跑
`python tools/real_gap.py`，预期 BINARY 从 6.99 掉到 6.2 附近、其余四支数字不变。

注意：`0x84` 是在 NX Studio 里实测的；机身滤镜菜单同样五档，但**机身读入 NCP 后
这一格是否照单全收，还需要实拍一帧确认**（拍一张 BINARY，看红/绿区域明暗有没有变）。
