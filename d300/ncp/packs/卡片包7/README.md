# 第七轮卡片测试说明

## 一、这次的结论：曲线一直是好的，是「探针」写错了

对比 DSC_5295–5298（01 STD / 02 GAM / 03 MNCP / 04 SNCP）：

| 照片 | 槽位 | 与 01 STD 的平均差 | 结果 |
|---|---|---|---|
| 5295 | 01 STD（52B 原厂） | — | 基准 |
| 5296 | 02 GAM（我方 gamma 0.45） | **1.49** | ❌ 没执行 |
| 5297 | 03 MNCP（**原厂 M.NCP 原样**） | **21.89** | ✅ 执行了，L 均值 54.6 → 76.4 |
| 5298 | 04 SNCP（**原厂 S.NCP 原样**） | **38.44** | ✅ 执行了，中段反向 |

03/04 只是把原厂文件改了个名字，曲线照样进画面。可见**机身完全能执行 NCP 里的 638 字节曲线**。

那么 02/03 的差别只剩一个：**八个滑块里的第 2、3 个字节**。

```
原厂 638B 文件（带曲线）：[41][42] = 01 01
我方探针文件（带曲线）  ：[41][42] = 80 80   ← 错在这里
```

统计仓库里 116 个原厂文件，无一例外：

- **52 字节文件**（只有配置、没有曲线）→ `80 80`
- **638 字节文件**（带曲线）→ `01 01`

`0x01` 的含义是「**对比度 / 亮度交给曲线**」，`0x80` 是「数值 0（线性）」。写了 `80 80`，机身就按线性对比度出图，把后面那 578 字节曲线块整块丢掉——既不报错，也不提示，看起来就像"曲线没生效"。

**顺带一个好消息**：`out/` 和 `out_comp/` 里那 60 个正式滤镜，本来写的就是 `01 01`（生成器走的是 `sliders_for(has_curve=True)`）。也就是说**它们从第一版起就是对的**，只是之前用探针测试，一直没被测到。

**另一个顺手修掉的坑**：`out/`、`out_comp/` 里 11 + 11 个单色滤镜底子码写的是 `0x0004`，而真机第四轮已证明单色必须写 `0x064D`（写 `0x0004` 列表里根本不出现）。现已全部改正，`ncp_d300.py` 的 `pick_base()` 也改成返回 `0x064D`。

## 三、怎么拍

1. 把 `卡片包7\NIKON` 整个拷到卡根（覆盖旧的）。
2. 机身：拍摄菜单 → 管理优化校准 → **载入/保存 → 复制到相机**，按顺序把 8 个载进 `C-1 … C-8`。
3. 用 **M 档、固定白平衡、主动式 D-Lighting 关、高 ISO 降噪关、长时间曝光降噪关**，同一场景同一曝光，依次拍 8 张。
   - 顺序很重要：**01 → 02 → 03 → 04 → 05 → 06 → 07 → 08**。
   - 建议拍一个**有连续影调的场景**（比如带渐变的白墙 + 一个亮主体），阶跃那张才好看出来。
4. 8 张都发我（或直接说文件名）。

## 四、这次能一次回答两个问题

### 问题 1：机身有没有那个「H 前置变换」

「H」是尼康工坊（NX Studio）在套用 NCP 曲线**之前**先做的一次固定影调压缩：中间调 −18、两端归零。之前八组对比已证实工坊有 H。

机身有没有，就看 `02 STEP`：

- 阶跃（从黑跳白的那一圈）落在 **输入 128** → **机身没有 H**，正式发布用 `out/`（未补偿）。
- 阶跃落在 **输入 ≈146** → **机身有 H**，正式发布用 `out_comp/`（补偿版）。

18 级的位移在照片上非常明显，不会看错。

### 问题 2：真实滤镜在机身上好不好看

`03 GAM` 的预测值（如果曲线生效）：

| 输入灰度 | 无 H | 有 H |
|---|---|---|
| 64 | 137 | 125 |
| 128 | 187 | 175 |

只要 03 明显比 01 亮（中间调从 64 抬到 130 上下），曲线就算彻底跑通。

`04/05`（POP）和 `06/07`（BINARY）是同一滤镜的未补偿 / 补偿两版，**哪一版更接近工坊里的观感，就说明机身有没有 H**，和 STEP 互相印证。

`08 U-SEP` 是单色底子 + 曲线 + 棕褐调色同时上，验证「单色能不能带曲线」——第四轮只证明了单色本身能出，没证明能带曲线。

## 五、后续（拿到结果后）

- **无 H** → `out/` 就是最终版，直接做一个「卡根目录 + NIKON\CUSTOMPC」双份的发布包。
- **有 H** → `out_comp/` 是最终版。
- 两种情况下 App 的导入路径都要改成 `A:\NIKON\CUSTOMPC\PICCONxx.NCP`（现在写的是卡根，机身读不到）。
