## 一、怎么用

1. 把 `NIKON` 文件夹整个拷到存储卡**根目录**（合并，覆盖旧的）。
   卡上的路径必须是 `X:\NIKON\CUSTOMPC\PICCONnn.NCP`，机身只读这一处。
2. 机身：**拍摄菜单 → 管理优化校准 → 载入/保存 → 复制到相机**。
3. 列表里会显示全部 30 个名字，选一个存进 `C-1`，再选下一个存 `C-2`……
4. 选择时按住机身左前方的**优化校准按钮**并转动主指令拨盘，屏幕显示 `C-1`／`C-2` 即生效。

> **机身只有 9 个自定义槽位（C-1 … C-9）**，30 个滤镜请分批导入。
> 分 4 批最省事：01–09、10–18、19–27、28–30。
> 换批次时不必删卡上的文件，机身列表始终显示全部 30 个。

## 三、这一版凭什么变好

### 1. 饱和度 / 色相滑块终于写真值（第二版）

第一版把八个滑块里的饱和度、色相一律写 `0x80`（数值 0），等于没动 —— 而 `SILENCE`、`BLEACH`、`DRAMA`
这类滤镜的核心动作就是大幅降饱和。第二版用 4 张实拍标定图把两档量出来：

- 饱和度：平均每档 **×1.118**（`SAT-1 → SD` 实测 1.1274、`SAT-1 → SAT+1` 实测 1.1351）；
  倍率**不是常数**，越往外越没劲（0→+1 是 1.114，+2→+3 只剩 1.059），累计 +3 = 1.275、−3 = 0.648；
- 色相：每档 **3.83°**。

### 2. 影调按「留出」重拟合，端点按斜率外推（第二版）

先用上半幅拟合、只看下半幅打分来挑曲线结构，结构定了再用全幅重拟合 —— 这一步挡住了过拟合。
首末几档像素不足时不再用 `np.interp` 平推，而是按有效样本斜率外推，暗部不再被抬高 3–6 级
（`POP` 6.0 → 2.0、`TOY` 6.0 → 1.3）。

### 3. 判据换成 8 折交叉验证（第三版）

第二版用「上半幅拟合、下半幅打分」，这个切法暗含一个偏置：画面上下两半的亮度分布本来就不同。
换成 2×4 = 8 折后，救回的主要是一支 —— `DEEPTONE_MONOCHROME` 12.23 → **8.76**，
第二版判它"不值得动"是切法造成的假象。

## 四、三条真机定案

### 1. 曲线能不能用 → 能用，但要一个开关

NCP 文件 52 字节配置区里那「八个滑块」，第 2、3 个字节是**对比度 / 亮度的控制方式**：

```
0x01 = 交给自定义曲线
0x80 = 数值 0（线性，忽略曲线）
```

统计 116 个尼康原厂文件，无一例外：**52 字节文件（无曲线）写 `80 80`，638 字节文件（有曲线）写 `01 01`**。
写成 `80 80` 时，机身按线性出图，后面那 578 字节曲线块被**静默丢弃** —— 不报错、不提示，看起来就像"曲线没生效"。

> 用原厂的 `M.NCP`、`S.NCP` 只改名丢进卡里，机内效果明显（与标准底子的平均差 21.9 / 38.4 级）；
> 我们自己的 gamma 曲线用 `80 80` 写，差 1.49 级（等于没动）。改回 `01 01` 后立刻生效（DSC_5301，中间调 15 → 67）。

### 2. 机身也有「H 前置变换」

在曲线之前，机身会先做一次固定的影调压缩 H（中间调 −18 级、两端归零）。这不是 gamma，也不是 S 曲线。
证据：写一条 v=128 的硬阶跃曲线，输出从黑跳白的**分界落在输入 144.6**（模型预测 H⁻¹(128)=146.1）。
再用 gamma 0.45 反推整条 H，与尼康工坊（NX Studio「与照相机兼容」）测出的 H 对比：**平均差 +0.95 级，标准差 1.04 级**。

> 也就是说：**机身 H ≡ 工坊 H**。这一点决定了补偿只能做一份 —— 做完之后，卡里出图和工坊出图是同一个结果。

### 3. 补偿

既然机身也会套 H，直接写目标曲线 T 会得到 T(H(x))（整体偏暗）。
本包里写的都是 **C′ = T ∘ H⁻¹**，机身算出来是 `C′(H(x)) = T(x)`，正好是目标影调。

实测校验（DSC_5302 / 5303，POP 的未补偿版与补偿版）：两条链路对模型的残差都在 **1 级左右**，属于 JPEG 量化噪声量级。

## 五、已知限制

- **色彩不能完全复刻，而且现在能说清差多少。** 把 30 支的残差和"这支滤镜自身的色罩强度"放在一起，
  相关系数是 **r = 0.80**（彩色底 26 支 r = 0.85）：`残差 ≈ 3.65 + 0.217 × |色偏|`。
  也就是说 **3.65 级是这套工具的地板**，剩下的差距几乎全是色罩 —— 而 NCP 的曲线是**单条亮度 LUT**，
  没有分通道曲线，做不出色罩。反过来，残差与"这支浓不浓、亮不亮"已经无关（r = 0.03 / −0.03），
  那部分第二版已经吃干净了。
- **四支调色滤镜（13–16）走的是另一条路**：单色底子 + 着色档，能原生造色罩，所以不怕色偏；
  代价是丢掉"保留部分彩色"，转而卡在彩度上。
- **下降饱和类打不满**：`SILENCE` 原版彩度只有标准的 0.28×，而滑块 −3 档实测只能到 0.648×，
  机制上就压不到，只能靠曲线把亮度搬对。
- **名字只能用英文**（20 字节 ASCII）。机内名字字段不是 UTF-16，写中文会变乱码。
- **单色滤镜的底子码必须是 `0x064D`**，彩色必须是 `0x0001`；写错（如 `0x0004`）机身列表里那一项根本不出现。
